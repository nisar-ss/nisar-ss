## Featured Projects

### Data Warehouse Optimization with PySpark and SQL
**Tech Stack:** Python · PySpark · SQL · Apache Spark · Pandas  
**Duration:** January 2025 – May 2025

**Business Problem:** Inefficient query performance and slow data loading in a Redshift data warehouse processing 10+ GB daily, causing BI dashboard timeouts and delayed reporting.

**Solution & Contribution:**
- Analyzed 200+ slow queries using `SVL_QUERY_SUMMARY` and system tables to identify performance bottlenecks
- Implemented data partitioning, indexing, and query optimization techniques using PySpark and SQL
- Redesigned schema structures from flat tables to a star schema with optimized distribution styles and sortkeys

**Business Impact:**
- Reduced query p95 latency from **45s to 12s**
- Streamlined ETL workflows and improved downstream analytics reliability

**Tech Stack:** Python · Apache Airflow · SQL · ETL Tools · Data Modeling  
**Duration:** August 2023 – December 2024

**Business Impact:**
